## 🚀 Introduction

Constructor is a helpful tool designed for the HTML team to streamline the creation of newsletters and landing pages. It supports localization by integrating with a translations spreadsheet, making it easier to build content for multiple languages.

## How to Build/Use

Constructor is an app intended for internal use; there is no production build. To use the app:

<ol>
  <li><span style="color:#e67e22;">Clone this repository (download the code to your computer):<br>
    <code>git clone https://github.com/BelianiRafal/Constructor_project.git</code>
  </span></li>
  <li><span style="color:#e67e22;">Go into the project folder:<br>
    <code>cd Constructor_project</code>
  </span></li>
  <li><span style="color:#e67e22;">(Optional - but recommended) Switch to the branch you want to work on:<br>
    <code>git branch</code> <br>
    <code>git switch &lt;branch-name&gt;</code>
  </span></li>
  <li><span style="color:#e67e22;">Update your code to the latest version:<br>
    <code>git pull</code>
  </span></li>
  <li><span style="color:#e67e22;">Install all dependencies (this downloads everything the app needs):<br>
    <code>pnpm install</code>
  </span></li>
  <li><span style="color:#e67e22;">Copy the environment template and create your own config file:<br>
    <code>copy .env.template .env</code> <br>
    Then open <code>.env</code> in your editor and fill in the required values.
  </span></li>
  <li><span style="color:#e67e22;">Start the app:<br>
    <code>pnpm start</code>
  </span></li>
</ol>
